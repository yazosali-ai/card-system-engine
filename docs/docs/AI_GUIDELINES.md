# AI Development Guidelines

All AI contributors must:

1. Read the relevant documentation before making changes.
2. Follow the approved architecture.
3. Explain significant architectural changes.
4. Write tests for implemented functionality.
5. Avoid game-specific assumptions.
6. Avoid game-specific cards and effects.
7. Avoid fictional lore.
8. Identify edge cases.
9. Preserve working functionality.
10. Document significant decisions.

The repository must remain generic.

The engine must be capable of supporting multiple different card games without requiring game-specific logic inside the core system.
