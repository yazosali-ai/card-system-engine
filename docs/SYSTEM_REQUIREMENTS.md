# Generic Card System

This repository develops a reusable card-game system.

The system must remain independent from any specific game.

It must not contain:

- Game-specific cards
- Game-specific card effects
- Game-specific lore
- Game-specific characters
- Game-specific terminology

The system will eventually support multiple independent games.

Primary development goals:

- Generic game architecture
- Rules engine
- Card system
- Action system
- State management
- Turn and phase management
- Resource management
- Player management
- AI integration
- Automated testing
- Simulation
- Validation
- Extensibility
